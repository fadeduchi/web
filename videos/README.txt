MOD PREVIEW VIDEOS
==================

Place your preview videos in this folder with these exact names:

  spawner-protect.mp4
  glazed-addon.mp4

Supported format: .mp4 (H.264) works best in all browsers.

If your files have different names, either rename them OR edit
js/script.js — change previewVideo for each mod, e.g.:

  previewVideo: "videos/my-spawner-clip.mp4",

Test with a local server (required for video + downloads):

  cd C:\Users\titie\minecraft-mods-hub
  python -m http.server 8765

Then open Details on Spawner Protect or Glazed Addon.

Tip: Keep each preview under ~2.3 MB if you host on the same
plan as your mod downloads.
